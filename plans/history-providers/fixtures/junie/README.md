# Native Junie 3110.7 synthetic capture

The fixture is generated by the released JetBrains Junie 3110.7 jar, SHA-256
`24f2a09a3beb6e8b7bc6d53e55455b0d7f8e31436548f328abcd505fb7f58b9b`.
Its npm shim package is `@jetbrains/junie@3110.7.0` (SHA-256
`373d8622d280bdd51a6b329c819a746564a41574ebb7a8fbb7d8f2874c0a9992`).
The package's `postinstall.js` selects the 3110.7 macOS arm64 release asset.
Use an isolated temporary home; the harness never runs a model or reads real
Junie history. A JDK 21 and that jar are sufficient.

From the repository root, set `JUNIE_JAR` to the extracted released jar and
`CAPTURE_HOME` to a newly empty temporary directory, then run:

```sh
javac -proc:none -cp "$JUNIE_JAR" plans/history-providers/fixtures/junie/{WriteCapture,ReadOracle}.java
java -Dsynthetic.home="$CAPTURE_HOME" -cp "$JUNIE_JAR:plans/history-providers/fixtures/junie" WriteCapture initial
java -Dsynthetic.home="$CAPTURE_HOME" -cp "$JUNIE_JAR:plans/history-providers/fixtures/junie" WriteCapture resume
java -cp "$JUNIE_JAR:plans/history-providers/fixtures/junie" ReadOracle "$CAPTURE_HOME" session-261021-120000-demo
```

The two `WriteCapture` invocations are separate processes. The second updates
the native index and appends to the same journal. `ReadOracle` invokes
`SessionStore.readStoredEventsFromFile` in a third process; its expected output
is `official-reader.tsv`. The checked-in event timestamps come from the native
writer clock on 2026-10-21. Paths and message text were synthetic before any
writer call, so no redaction or schema rewriting was needed. Compare native
IDs, type, timestamp and text with the reader TSV; clock values change on a
fresh run. The fixture is staged at
`crates/ai-hist/tests/fixtures/junie/native/.junie/sessions/`.

Coverage limit: `SubagentSpawnedEvent` proves a parent-side notice only. The
capture does not include a child transcript or native child identity. The
released renderer writes derived Markdown under `subagents/`, but that is not
accepted as extra source messages without a native child event capture.
